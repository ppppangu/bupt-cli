北邮算力工具 bupt

重要声明：本工具是面向北邮师生的第三方工具，与学校及「人人有算力」平台无隶属或委托关系。
登录时输入的学工号和密码只提交给学校统一身份认证的 HTTPS 页面，不经过其他服务器；
会话与密钥加密保存在本机 ~/.bupt/。请自行遵守学校和平台规定，违规使用造成的封号、
配额和合规后果由使用者承担。

收到这份安装包后，用自己的学校账号登录即可。先将整个 ZIP 解压，再使用解压目录中的文件。

安装

macOS        打开“终端”，输入 cd 和一个空格，把解压后的文件夹拖入终端，再按回车。
Linux        在解压后的文件夹中打开终端。
Windows      在 PowerShell 运行 wsl -l -v，查看 Linux 发行版的 VERSION 是否为 2。
             首次安装 WSL2 可按 Microsoft 的说明操作。
             https://learn.microsoft.com/zh-cn/windows/wsl/install
             在解压目录打开 Windows 终端，输入 wsl。进入 Linux 后，运行 ls install.sh
             确认当前目录能看到安装脚本，再执行下面的安装命令。

依次执行以下命令。安装脚本会识别处理器，校验程序，并安装到当前用户的 ~/.local/bin。

    sh ./install.sh
    export PATH="$HOME/.local/bin:$PATH"
    bupt version

如果新开终端后提示找不到 bupt，把上面的 export 行加入当前 shell 的启动文件。
macOS 默认 zsh 可放在 ~/.zshrc，Linux 或 WSL 常用的交互 bash 可放在 ~/.bashrc。

首次登录

    bupt tui

在首页选「首次设置这台电脑」，再选「登录学校账号」。命令行也可依次运行 bupt init 和 bupt login。
校外网络认证过期时，先扫码通过 WebVPN，再完成学校统一身份认证。
支持统一认证密码的账号也可以运行 bupt login --sso-password，按提示在终端中输入学工号和密码。

Linux 或 WSL2 上，如果用户级 systemd 不可用，可在 TUI 内选择「作为本机进程启动」。
系统重启后，可回到同一工作区再次启动。命令行用户也可运行 bupt init --install=false。

常用查询

    bupt api model           查模型 ID、价格、上下文和状态
    bupt api usage           查余额和用量
    bupt api key             查看本账号的 API Key
    bupt compute catalog     浏览算力模板和配额
    bupt compute instance    查看本人实例、预留状态和期限
    bupt status              查看平台总览
    bupt logout              退出当前配置的学校登录会话

首页按 R 进入「模型 API」，选「在线调试 → 对话」，选择模型并编辑「你的问题」。
Enter 换行，Esc 保留草稿。选择「发送请求」后，回复显示在原页，可修改输入再次发送。
选择或创建密钥后会返回当前任务。选择「生成调用代码」可用当前输入生成 Python 或 curl 示例。

首页按 S 查看裸算力服务器，在「我的实例」连接节点或在「创建实例」选择规格。
按 U 查看余额、模型用量和服务器账单。按 ? 打开「帮助与账户」，可阅读教程或登录学校账号。
命令行教程使用 bupt help tutorial。「账户及相关设置」可调整顶栏和自动核验。
个人配置、状态与凭据默认位于 ~/.bupt/。

单独输入 bupt 会打印帮助。全屏界面用 ↑↓ 选择或阅读，→ 展开或查看，Enter 执行选中动作，Esc 返回，q 退出。
启动或创建实例会占用学校额度，请先在界面预览规格、时限和清理策略。
使用本地控制器时，电脑休眠会暂停它向学校提交管理操作。

更新

在没有活跃托管任务时，解压新版安装包，再次执行 sh ./install.sh 和 bupt init。
用 bupt version 查看客户端版本，用 bupt agent status 检查控制器。
配置、登录会话和设备密钥保存在各自账户的用户目录中。分发给同学时转发原始 ZIP 即可。

# 结束实验并归还算力

先在本机运行 `bupt compute instance show lab`。如果托管策略已经完成停机并释放计算预留，只需核对状态和账单。若作业还在运行，先查看作业状态，确认可以中断后再操作。

| 实验结束后的打算        | 应采取的操作                  |
| --------------- | ----------------------- |
| 马上继续用同一台机器      | 退出 SSH，保留运行，留意托管截止时间和费用 |
| 暂停运行，保留已分配的算力   | 停机。计算预留和磁盘仍可能计费         |
| 归还 GPU，暂时保留实例磁盘 | 先停机，再释放计算预留。磁盘受学校回收策略约束 |

## 归还本教程使用的 GPU

仍需取回文件时，在 SSH 可用期间先下载。例如，程序生成了 `result.txt`，可执行 `bupt cp lab:result.txt ./result.txt`。上一节的示例把机器名写在作业日志里，可直接按作业 ID 查看。

如果 `lab` 仍在运行且已决定归还，在**本机**依次执行。等待前一步成功后再执行下一步：

```sh
bupt compute instance stop lab --wait
bupt compute instance release lab --wait
bupt compute instance show lab
```

已经停机但仍有预留时，从第二条开始。最后确认实例**已停机、计算资源已归还**。若状态为 `cleanup_pending`，检查学校登录状态和当前预留，等控制器继续核对。磁盘存储可能继续计费，重要数据请另存。[查看余额和账单](../../can-kao-yu-pai-cuo/usage.md)

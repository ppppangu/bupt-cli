# 查看余额和账单

刚发送过模型请求，或刚用完实例？先选和操作发生时间一致的统计周期，再查对应来源。模型明细记录调用和 Token，实例账单记录计算预留、存储等计量。

在工作台首页按 **U** 打开「余额与用量」。先选统计周期，例如「近 7 天」。按 **1** 到 **5** 可以在总览、模型 API、裸算力、趋势和明细之间切换，各视图沿用同一周期。

| 想核对的内容              | 在哪里看                |
| ------------------- | ------------------- |
| 还剩多少积分              | 「总览」的门户余额           |
| 哪个模型产生了调用和 Token 用量 | 「模型 API」或「明细」中按模型分组 |
| 某台实例有哪些账单           | 「明细」选择裸算力，按实例编号筛选   |
| 每天的变化               | 「趋势」选择模型 API 或裸算力   |

以下命令会列出最近七天的汇总。

```sh
bupt usage --days 7
```

开头会显示实际查询日期和学校时区，随后分别列出模型 API 和裸算力数据。门户实际扣除的积分与实例账单中的已公布计量分开显示。创建时看到的日价用于估算，最终金额以学校账单为准。

## 遇到缺失数据

界面中的横线表示金额或状态尚未确认。脚本可用 `bupt usage --days 7 --json` 检查 `compute.state` 和 `compute.data.complete`。若标记为 `partial` 且给出 `next_page`，用 `bupt compute usage --page N` 查看对应页，将 `N` 换成该页码。分页中断或记录缺少日期、金额时，不宜把可见行相加当作完整总额。

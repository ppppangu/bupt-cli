# 把模型接入自己的程序

从[第一次对话](../models.md)的结果页进入「生成调用代码」。这样生成的示例会沿用刚才的模型、问题和参数。已经知道模型 ID 时，也可以从「模型 API → 在我的程序中调用」开始。

1. 选择 Python 或 curl，再选择允许该模型的 Key。打开「环境配置与依赖」查看示例需要的环境变量。生成和预览代码都不会发送请求。
2. 在终端运行 `bupt api key`，找到这把 Key 的 **ID**。将下方的 `KEY_ID` 换成实际 ID，在个人私有目录使用一个全新的文件名导出完整密钥。

   ```sh
   bupt api key export KEY_ID --file ./research.key
   export BUPT_API_KEY="$(cat ./research.key)"
   ```

3. 回到工作台，关闭「环境配置与依赖」查看程序正文。按 **s** 保存；例如，把 Python 示例保存为 `ask.py`。在刚刚设置环境变量的终端进入该文件所在目录，运行 `python3 ask.py`。

收到模型返回的内容就说明接入成功。运行示例会产生一次新调用。请妥善保管导出的密钥文件，避免将它加入代码仓库。[核对本次用量](../usage.md)

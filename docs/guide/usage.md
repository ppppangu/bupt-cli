# 查看余额和账单

刚发过模型请求，或者刚用完一台实例？先把统计周期选成操作发生的那段时间，再查对应的来源——模型明细记录调用和 Token，实例账单记录计算预留、存储这些计量。

在工作台首页按 **U** 打开「余额与用量」，先选统计周期，比如「近 7 天」。按 **1** 到 **5** 能在总览、模型 API、裸算力、趋势和明细之间切换，几个视图共用同一个周期。

| 想核对的内容 | 在哪里看 |
| --- | --- |
| 还剩多少积分 | 「总览」的门户余额 |
| 哪个模型产生了调用和 Token 用量 | 「模型 API」或「明细」中按模型分组 |
| 某台实例有哪些账单 | 「明细」选择裸算力，按实例编号筛选 |
| 每天的变化 | 「趋势」选择模型 API 或裸算力 |

下面这条命令会列出最近七天的汇总：

```sh
bupt usage --days 7
```

开头会显示实际查询到的日期范围和学校时区，接下来分别列出模型 API 和裸算力的数据。门户实际扣除的积分，和实例账单里已经公布的计量是分开显示的；创建实例时看到的日价只是估算，最终金额以学校账单为准。

## 遇到缺失数据

界面里的横线表示这项金额或状态还没确认下来。脚本可以用 `bupt usage --days 7 --json` 检查 `compute.state` 和 `compute.data.complete`：标成 `partial` 并且带了 `next_page` 的话，用 `bupt compute usage --page N` 查对应那一页，`N` 换成实际页码。分页被打断，或者某条记录缺日期、缺金额的时候，不要把看到的几行直接加总当成完整数字。
